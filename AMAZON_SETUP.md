## 🚀 Amazon Official API Setup (FREE)

### Quick Steps:

1. **Sign up for Amazon Associates**: https://affiliate-program.amazon.com/
   - Takes 2-3 days for approval
   - Get your Associate Tag (like `yourstore-20`)

2. **Get API Keys**: https://webservices.amazon.com/paapi5/documentation/
   - Sign in with Associates account
   - Click "Add to App"
   - Get Access Key + Secret Key

3. **Add to .env.local**:
   ```
   AMAZON_ACCESS_KEY=AKIAIOSFODNN7EXAMPLE
   AMAZON_SECRET_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
   AMAZON_AFFILIATE_ID=yourstore-20
   ```

4. **That's it!** Your app will automatically use the official Amazon API with:
   - ✅ 8,640 FREE requests per day
   - ✅ Real product data
   - ✅ Official affiliate links
   - ✅ No monthly fees
